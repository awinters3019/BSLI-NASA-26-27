# BSLI NASA SSTR 3 Degrees of Freedom Simulink Model
Updated: 10/16/26

## How to get this on your computer
- Get GitHub Desktop app for your laptop! Super easy graphical interface
- Sign in with your GitHub account
- Click File --> Clone Repository --> Choose the 3-DOF branch --> Choose the folder on your computer you'd like to have as your MATLAB workspace for this project
- You should now see a normal folder on your computer there with everything!
- In MATLAB: The Model itself is under 3-DOF/model/TDOF_simulink_v2.slx. It should be able to run easily. The scripts are under 3-DOF/model/scripts, which has all the helper functions, initializing scripts, and a Monte Carlo script. For your first run, though, just open the Simulink file and hit "Run".

## How to edit the project
- Simulink works in *binary files*, meaning **only one person at a time can work on the Simulink**. I would recommend making a system such that only one person can work on it at a time, and a process for making commits.
-   Before opening/editing the Simulink, always hit "**Fetch/Pull Origin**" in GitHub Desktop to get the most recent version.
-   Ask permission to start working; once approved, feel free to edit it. 
-   Once done, **hit Commit/Push** from your end to update the entire model for everyone; at this point, announce you're done working.
